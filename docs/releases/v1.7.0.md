# Points Tracker 1.7.0

This release expands the local ledger with Choice Privileges, Leading Hotels of
the World, and Singapore Airlines KrisFlyer, while making manual values safer
and zero-balance expiration handling consistent across every program.

## Highlights

- Added Choice Privileges balance, member-number, status, and activity-based
  expiration tracking.
- Added Leading Hotels of the World balance, member-number, and activity-based
  expiration tracking.
- Added KrisFlyer balance and member-number tracking, plus the earliest
  displayed expiring-mile tranche as `amount · MM/YYYY`.
- Protected manual values from automatic page visits.
- Added confirmation before a row refresh replaces a manual value.
- Removed the extra manual-row action for switching back to automatic capture.
- Improved Capital One Miles balance capture.
- Made every zero-balance row display expiration as `N/A`, including automatic
  captures, manual values, older stored records, and imported backups.

## Choice Privileges

Choice reads the rendered account balance, member number, Member status, and
newest qualifying Points History activity. Active Gold, Platinum, Diamond, or
Titanium status displays `N/A`. A zero balance also displays `N/A`; otherwise
the ledger uses the program's 18-month inactivity rule.

## Leading Hotels of the World

LHW reads the rendered Leaders Club balance, member ID, and newest qualifying
earn or redeem activity. A zero balance displays `N/A`; otherwise the ledger
uses the program's 24-month inactivity rule.

## KrisFlyer

KrisFlyer reads the rendered balance and member number from the account
masthead. Under Miles validity, the earliest displayed expiring tranche is
stored with month precision and shown as `amount · MM/YYYY`. Zero balance, no
displayed tranche, and active PPS Club status display `N/A`.

## Manual values

Visiting a supported account page no longer replaces a manual value. An
explicit row refresh asks before switching back to automatic capture, and the
manual value remains intact unless the automatic update completes successfully.

## Privacy and maintenance

All new capture remains limited to allowlisted values rendered on official
account pages after ordinary website login. No credentials, cookies, private
API authorization, network interception, raw HTML, transaction history,
analytics, backend, or remote loyalty-data upload was added.
