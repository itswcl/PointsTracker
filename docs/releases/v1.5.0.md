# Points Tracker 1.5.0

This release adds Capital One Miles and expands the local ledger to twenty
supported rewards programs.

## Highlights

- Added Capital One Miles as a balance-only Credit Card row.
- Reads only the rendered whole-number value paired with the exact `Miles`
  label on the authenticated account-summary page.
- Excludes the neighboring Rewards cash value, promotional miles, editable
  fields, card details, account identifiers, and transaction data.
- Fails closed if multiple rendered Miles totals conflict, while preserving the
  last saved value and manual-edit fallback.
- Updated backup normalization, Credit Card sorting and totals, exact host
  permissions, documentation, and the fully synthetic README preview.

All data remains in the current Chrome profile. The extension does not request
or store credentials, cookies, private API authorization, card details,
transaction history, or raw account-page HTML.
