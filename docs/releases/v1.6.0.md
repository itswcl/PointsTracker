# Points Tracker 1.6.0

This release expands the local ledger to twenty-one rewards programs represented
by twenty-four independently tracked rows, adds reversible visibility settings,
and refines the popup's global controls.

## Highlights

- Added Southwest Rapid Rewards points and Flight Credits as separate Airline
  rows captured from one official account page.
- Added United Pooled Miles and United TravelBank alongside the existing
  MileagePlus row.
- Added shared-page batch capture so one refresh tab can update related rows
  without duplicate tabs or storage races.
- Added local Settings for hiding programs without deleting their saved
  balances, member numbers, expiration records, or manual overrides.
- Redesigned Settings as a dedicated ledger-style view with category sections
  and clear `Shown` and `Hidden` switches.
- Moved Setting, Update, Export, and Import to compact upper-right icons and
  reduced the upper-left metadata to the installed version.
- Kept miles and points first in the default Airline order, followed by the USD
  `UA TB` and `SW Credit` rows.
- Consolidated overlapping project documentation into Installation,
  Architecture, Live Acceptance, and Publishing guides with a central index.

## Southwest

`Southwest` stores the rendered `Available Points` total with `N/A` expiration.
`SW Credit` locally sums rendered Flight Credit amounts, displays USD with exact
cents, and uses the earliest real expiration date. If all displayed credits say
`Expiration: None`, no expiration detail is shown, or no credits exist, the row
displays `N/A`.

Only the aggregate Flight Credit total and earliest expiration are stored.
Individual credit identifiers, amounts, passenger details, and transaction
history are not retained. The cash row is excluded from the Airline points
total.

## United

The United account page now produces three independent rows:

- `UA Miles` for the MileagePlus balance;
- `UA Pool` for pooled miles; and
- `UA TB` for the TravelBank USD total and displayed expiration.

All three rows display the same captured MileagePlus number. TravelBank is
excluded from the Airline points total.

## Program settings

Every program is enabled by default. Disabling one hides the row, removes it
from totals and sorting, stops its rendered-page adapter, and causes the
background coordinator to ignore stale refresh observations. Re-enabling the
program restores its previously saved record.

## Privacy and maintenance

All new loyalty capture remains limited to allowlisted rendered account-page
elements after ordinary website login. No credentials, cookies, private API
authorization, network interception, raw HTML, individual credit records,
analytics, backend, or remote loyalty-data upload was added.

The release passed strict TypeScript, ESLint, 210 Vitest tests across 27 test
files, and the production Manifest V3 build.
