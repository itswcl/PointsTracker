# Points Tracker 1.4.0

This release expands the local ledger to nineteen rewards programs and refines
the compact three-column popup.

## Highlights

- Added IHG, Wyndham, Amex, Chase, Citi, and Bilt.
- Added the Credit Card ledger and separate category total.
- Chase sums every card balance shown on the Ultimate Rewards account selector
  while storing only the combined total.
- Login-required refreshes now bring the account tab forward and keep watching
  for up to three minutes.
- Airline and hotel rows display the last four member-number characters; click
  the suffix to copy the full locally stored number.
- Reordered the popup to Credit Card, Airline, and Hotel and removed category
  counts and redundant column titles.
- Fixed IHG Elite and Wyndham no-activity expiration handling, signed Bilt
  balances, Chase shadow-root totals, and compact-popup overflow.

All data remains in the current Chrome profile. The extension does not request
or store credentials, cookies, private API authorization, card details,
per-card balances, transaction history, or raw account-page HTML.
